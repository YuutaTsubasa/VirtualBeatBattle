# Claude → ChatGPT／Codex：虛擬音鬥樂 第一批美術請求（90 年代 anime90）

新遊戲《虛擬音鬥樂 Virtual Beat Battle》：6 鍵下落式節奏遊戲。**每一首歌都是一隻魔王**：軌道像一條往遠處收窄的路，
一路通到魔王的腳下；音符從魔王腳邊飛出來，角色站在判定線上把音符打回去（打中＝攻擊魔王）。左右同時押的時候角色會分出半透明的分身。

- 介面方向照使用者的概念圖：`art-work/rhythm-ui-concept-v1/01-solo-ui-concept.png`、`02-multiplayer-ui-concept.png`、`03-character-select-ui-concept.png`（「Blue Frequency」：冰白 #F5F6FC、鈷藍 #1450F5、墨藍 #101A33、少量青色 #2FC6FF，斜切的幾何、平行的節奏線、音波的圖樣）。
- 角色身分：沿用虛擬台麻館的半身像（`public/characters/<id>/normal.webp`，衣服就是麻將館那套）與動作圖（`public/sprites/<id>.webp`）。**不要換衣服、不要加耳機或未來感服裝**（概念圖裡的小翠是示意，以半身像為準）。
- 規格見 `art-inbox/README.md`。先做 **anime90**，其他五種等使用者看過再說。

這一批照美術流程分成「試做批」與之後的量產。**請先交包 1（試做批），等 Claude 接好、使用者看過再做包 2、包 3。**

## 包 1：`anime90-trial.zip`（試做批）

### 1. Logo：`ui/logo.png`（1400×560，透明）

- 主標：「虛擬音鬥樂」五個字，**「鬥」是鬥爭的鬥（不是「斗」也不是「門」）**；副標一行英文「VIRTUAL BEAT BATTLE」。除此之外不要其他字。
- 粗的斜體黑體（墨藍）、左右各一道鈷藍色的閃電／音波，像概念圖 01 左上那個。白色或淡色的背景上要清楚（遊戲裡放在白底）。
- 交件時回報：字的外框（不含透明邊）的 x、y 範圍。

### 2. 標題主視覺：`ui/title-scene.png`（1920×1080，不透明）

- 照概念圖 01 左上那張的右半邊：天空中的白色未來都市、光環、音波；**小翠**（照半身像的臉、綠色雙馬尾兩條都要看得到、粉紅蝴蝶結、水手服）朝畫面伸手、微笑。
- 遊戲會用斜線把畫面**左邊 38% 蓋掉**（放 Logo 和選單），所以人物與重點放在**右邊 60%**，臉在 x≈1250、y≈420 一帶。
- 不要文字、Logo、UI。

### 3. 小翠的「背面」動作圖：`characters/xiaocui/sprites/<動作>.png`（每張 512×512 透明，腳底在 (256, 496)）

遊戲裡角色站在判定線上、**背對玩家、面向畫面上方的魔王**（從背後、略高的角度看，3/4 背面）。現在用的是側面的動作圖，要換成背面的：

| 動作 | 說明 |
| --- | --- |
| `back-idle` | 背對鏡頭站好、準備迎擊（重心低、兩手握拳在身前） |
| `back-strike1` | 右手往前上方出拳（打向遠處的魔王） |
| `back-strike2` | 左腳往前上方踢（跟 strike1 輪流用） |
| `back-sweep` | 兩手往左右張開揮出（左右同時押時用） |
| `back-hold` | 兩手往前伸、掌心集氣（長押中，手前面可以有一點光） |
| `back-release` | 長押放開：大動作往上揮出的一擊 |
| `back-hurt` | 被魔王打到、往鏡頭這邊踉蹌後退 |

- **小翠的兩條雙馬尾從背後都要看得到**，各自從髮根到髮尾，粉紅蝴蝶結在兩側。
- 交件時回報：每張的腳底位置與頭頂 y（遊戲會檢查跟現有圖的大小一致）。

### 4. 原創魔王曲的背景：`environment/og-speedcore.png`（1920×1080，不透明）

- 曲子：「終焉頻率」（Speedcore 200 BPM，最後的魔王）。場景：**雲海之上的一座黑色音塔頂端的競技場**，紅色與鈷藍的音波環、裂開的天空。
- **構圖很重要**：魔王站在畫面中間 **(960, 400)** 的位置（腳底），那裡要是一個平台／舞台的盡頭；從那裡往畫面下方，遊戲會蓋上一條往鏡頭展開的軌道（中間下方 55% 會被蓋住）。左右各 25% 會放 HUD（左邊角色資訊、右邊分數），不要太花。
- 遊戲會把背景壓暗，所以可以畫得比一般亮一點、對比清楚。不要文字、人物、魔王本身。

### 5. 原創魔王：「終焉指揮者」`bosses/conductor/<動作>.png`（每張 768×768 透明，腳底在 (384, 744)，面向右，遊戲會左右翻轉）

- 設計：高大、披著長斗篷的指揮家，手上拿著光做的指揮棒，身邊飄著碎掉的五線譜與音符；面具或遮住上半臉的帽簷。墨藍＋暗紅＋一點鈷藍光。
- 9 個動作（跟闖天下的魔王一樣）：`idle` `walk1` `walk2` `windup`（舉起指揮棒，準備丟攻擊）`slam`（往下揮）`hurt` `fall` `down` `charge`（全身發光集氣）。
- 交件時回報：每張腳底位置、頭頂 y。

### 6. `layout-metrics.json`

上面要回報的數字放這裡（也可以寫在留言裡）。
